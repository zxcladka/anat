# Конкурентный разбор: тренажёр анатомии для медстудентов

Дата: 2026-09-04. Цены — как показаны на страницах при выгрузке (USD, если не указано иное). Пометка «⚠» = не удалось верифицировать напрямую. Reddit для краулера закрыт, сентимент взят из Trustpilot, App Store, Anki-форумов и обзоров.

## 1. Kenhub

- Ядро: атлас 5 000+ иллюстраций, 1 790+ статей, 500+ видео, 485+ квизов, гистология/радиология. Веб-only, нативного приложения нет.
- Квизы: 3 типа (basic identification, advanced identification, exam/clinical), muscle-квизы (attachments / innervation / function), адаптивный алгоритм «слабые места до мастерства», встроенный spaced repetition, custom quiz builder, переключение Latin/English даже в бесплатном аккаунте. https://www.kenhub.com/en/quizzes
- Партнёрское приложение Daily Anatomy Flashcards (iOS 4.8★ / 7.4K): жалобы — нет латинских корней («massive oversight»), мало контента.
- Цены: $19.50/мес; $43.50/3 мес; Lifetime $145; 7-дневный возврат. Институциональных цен нет. В 2022 было $39/мес и $250 lifetime — снизили. https://www.kenhub.com/en/pricing
- Отзывы: хвалят квизы, дашборд слабых мест, Latin/English; ругают цену помесячно, длинные видео, нет кадаверных фото, квиз говорит только «верно/неверно» без объяснения, сброс прогресса при выходе. https://willpeachmd.com/kenhub-review
- Маркетинг сместился на USMLE: «7,3 млн пользователей, 1 000+ вузов».

## 2. Complete Anatomy (3D4Medical / Elsevier)

- 3D-модели, Gray's virtual dissection, 550+ радиологических снимков, AR, 1 500+ видео, 130 квизов; 20 млн скачиваний, 500+ вузов.
- Цены: Student $74.99/год, первый год $39.99; Professional $99.99; Institutional по запросу. Триал 3 дня. https://store.3d4medical.com/
- 2024–2026: веб-версия (06.2025) сначала только для институций; полнотелая интерактивная радиология (2026); 3D-мозг beta (08.2026). https://3d4medical.com/updates
- Жалобы: тяжёлое, перегрев, неудобный поиск, квизы только multiple choice, «party trick», без подписки — демо, медленная поддержка.

## 3. Visible Body

- Human Anatomy Atlas 2026: разово $24.99 (iOS 4.8★ / 21K). Suite: Student $34.99/год, Professional $199/год, институциональная лицензия по запросу.
- Инструменты: 3D-флешкарты с шэрингом, 3D dissection quizzes, MCQ, Lab Activities, 7 языков, Courseware через Cengage с авто-проверяемыми заданиями. https://www.visiblebody.com/anatomy-and-physiology-apps/human-anatomy-atlas
- Жалобы: нет аудио-произношения (просят годами), сбрасывается вид; просят «type-in answer, select the correct muscle» — больше форматов квиза.

## 4. Anki + AnkiHub + AnKing

- Anki бесплатна (AnkiMobile $24.99), FSRS встроен с 23.10, FSRS-6 по умолчанию. 86,2 % опрошенных медстудентов используют Anki, 66,5 % ежедневно; AnKing скачан 300 000+ раз.
- 02.02.2026: Damien Elmes передал стюардство AnkiHub. https://www.usedby.ai/blog/anki-transition-damien-elmes-transfers-core-stewardship-to-ankihub
- AnkiHub: Core $6/мес или $66/год (живые колоды, AnKing Step 30 000+ карт), Premium $10/мес (Smart Search, AI, интеграция Boards & Beyond и First Aid), Lifetime $240. 04.2026: Smart Search на Mistral OCR (PDF/скан → карточки). https://www.ankihub.net/
- Любят: живые обновления без потери прогресса, теги под ресурсы, коллаборативные правки. Болит: настройка аддонов, лавина повторов, колода не совпадает с программой вуза, Anki «уродлива и сложна».

## 5. Quizlet

- Plus $7.99/мес или $35.99/год с месячными лимитами (3 practice tests, 20 Learn-сессий); Plus Unlimited $44.99/год.
- Механики: Learn (адаптивный SRS), Test, Match, Q-Chat (закрыт 06.2025), Magic Notes (PDF/фото → карточки).
- Google Play 4.7★ против Trustpilot 1.4★ (646): «Learn locked behind paywall», принудительная реклама, списания после отмены. Урок: пейволл на базовый режим обучения убивает репутацию. https://www.trustpilot.com/review/quizlet.com

- Real Bodywork: Learn Muscles — quiz maker (name/action/origin/insertion), аудио-произношение; Muscle & Bone 3D — 9 типов квизов вкл. spelling; промахи в Favorites.

## Что из этого стоит взять (ранжировано по силе доказательств)

1. Стрик «одна 5-минутная сессия в день» + freeze/repair.
2. Streak-saver пуш вечером + подбор шаблонов.
3. Friend/group streak внутри учебной группы (до 5).
4. Недельные лиги внутри курса/потока.
5. Streak Wager на 7 дней за внутреннюю валюту.
6. Free = 5 минут раз в N часов, Premium = безлимит (вместо пейволла на режим).
7. FSRS + «живые» официальные колоды с эрратой без потери прогресса.
8. Импорт .apkg с тегами + маппинг на силлабус вуза.
9. 5+ форматов ответа на одной диаграмме: тап, drag-label, выбор, ввод текста, spelling.
10. Адаптивный drill слабых мест + объяснение после каждого ответа.
11. Custom quiz builder по объёму модуля.
12. Тройной переключатель Latin / Ukrainian / English + латинские корни.
13. Аудио-произношение латыни.
14. Сохранение прогресса, sync, PWA/офлайн.
15. Цена: дешёвый годовой, intro-цена на первый год, Lifetime ~4× годового.
16. Институциональная лицензия с кабинетом преподавателя и авто-проверяемыми labeling-заданиями.
17. Smart Search: лекция/PDF → карточки к ней.
18. Ежедневный дайджест «сегодня к повторению N».
19. Weekend Amulet / пауза на сессию.
20. Копирайт-тесты и явный выбор дневной цели.
21. Бейджи на 7-й день.
22. Group-buy скидка.
23. Мнемонические картинки на карточке структуры.
24. Не наказывать за ошибки (без «сердец»).
25. Anki как канал: экспорт колод, аддон, бесплатная колода как лид-магнит.
