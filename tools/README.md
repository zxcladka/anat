# Інструменти для поповнення атласу

Схеми беруться з Wikimedia Commons (SVG з номерами) та з атласу Sobotta 1909 (American ed., Public domain, файли `Sobo 1909 N.png`).

Конвеєр для пластини Sobotta:
1. `python3 ocr.py "sobo/Sobo 1909 N.png"` — tesseract читає підписи, пише `ocr/N.json` (рядки й блоки з координатами у %).
2. Відкрити `proc.html` через локальний http-сервер (наприклад `python3 -m http.server 8766`) і запустити `python3 upsrv.py` (приймає POST і зберігає у `dl/`).
   У консолі: `await runOcr2(N, 'slug', {})` — стирає підписи (детектор гліфів + OCR, з перевіркою білої рамки), вирівнює білий, зберігає `dl/slug.jpg` і `dl/slug.marks.jpg`.
3. Додати набір у `limb_sets.py` (або аналогічний файл): назва, категорія, список `(ключ_терміна, x%, y%)` — координати центру підпису.
4. `python3 build_data.py` → `atlas/data.js`. Скопіювати jpg у `atlas/`, підняти `?v=` у `index.html`.

`vert_map.py` — приклад для хребців (координати з рядків детектора), `hand_sets.py` — кисть, `limb_sets.py` — лопатка, плечова, передпліччя, таз, стегнова, гомілка, стопа.

## Перевірка інтерфейсу (скріншоти)

`node tools/shots.mjs tasks.json` — запускає headless Chrome через DevTools Protocol, емулює пристрій, виконує JS і робить скріншоти.
Формат tasks.json: `{"width":390,"height":844,"mobile":true,"dark":true,"steps":[{"url":"http://127.0.0.1:8791/index.html#/today","wait":1000,"shot":"today","full":true},{"eval":"document.title"}]}`.
Спершу підняти `python3 -m http.server 8791` у корені проєкту. У кінці скрипт друкує помилки консолі.

## Структура коду

`index.html` — розмітка і стилі ядра; `js/app.js` — ядро (атлас, тренажер, пошук, SRS, «Сьогодні», прогрес); `js/decks.js` — колоди карток; `js/blitz.js` — бліц; `css/modules.css` — стилі модулів. Модуль додає маршрут через `ROUTES.name = parts => …`, блок на «Сьогодні» через `EXT.today.push(fn)`, лічильник у бейдж через `EXT.badge.push(fn)`, асинхронну ініціалізацію через `INIT.push(fn)`. Після правок js/css підняти `?v=` у index.html.

## Програма курсів

`atlas/curriculum.js` — курси → модулі → теми; у кожної теми `sets` — id наборів з `data.js`. Додати схему до теми = дописати id у масив. Новий курс — новий об'єкт у `courses` (для порожнього курсу лишити `modules: []`).

## Перенесення пінів на кістку (пластини Sobotta)

Раніше піни стояли там, де на пластині був текст підпису. `tools/relocate_pins.py` знаходить виносні лінії (Хаф по тонких лініях поза кісткою), веде кожну до краю кістки й далі по пунктиру на кістці, і переносить пін у кінець лінії; без лінії — на найближчий край кості. Запуск: `.venv/bin/python tools/relocate_pins.py [set-id …]` (оверлеї в `tools/overlay/`), потім `--apply` (пише в `atlas/data.js`, резервна копія `data.js.bak`). Ручні виправлення після перевірки за оригіналами — у `tools/pins_fixed.json` (застосовуються поверх). Потрібні `opencv-python-headless` і `numpy` у `.venv`.

## Лексикон

`atlas/lexicon.js` — `en`: латинський термін → англійська (Terminologia Anatomica); `roots`: початок латинського слова → українське значення (пошук найдовшого префікса, суфікс не довший за 6 літер). Розбір терміна робить `etymology(la)` в `js/app.js`; вимова — `speak(text)` через speechSynthesis (голос la → it → es). Плутанина зберігається в `anat.confuse` (`noteConfusion`), показується в `explainHtml`.

## Векторні схеми (Wikimedia SVG)

`tools/svg_clean.py <png-dir> [set-id …]` — бере растр SVG (рендер headless Chrome, 2000 px), знаходить виносні лінії, веде їх по кольору поверх рисунка, переносить піни на кінці, стирає лінії (на білому полі — зафарбовує, поверх рисунка — inpaint) і зберігає `atlas/<id>.png`. `--apply` вписує нові файли й координати в data.js. Набори з лінійними рисунками (`NO_STRAY`) — без стирання на полях. Ручні правки після візуальної перевірки — у `tools/pins_fixed.json`. Композити для перевірки робились у scratch (оригінал + сітка у відсотках + наші піни).

## Крок 1

`tools/krok/src/` (не в git) — офіційні буклети PDF; `tools/krok/ocr_booklets.sh` — OCR відсканованих (tesseract ukr+eng, сторінка ділиться навпіл); `raw2/*.txt` — текст із правильним порядком колонок; `parse_krok.py` → `atlas/krok1.js`. ## Фінальне очищення схем (2026-09-05)

`tools/svg_dom_clean.html` — сторінка для headless Chrome (`tools/shots.mjs` з кроком `eval: "run('<id>')"`): завантажує оригінальний SVG (`svgsrc/<id>.svg`, дістаються з git: `git show f8a08be^:atlas/<id>.svg`), прибирає в DOM підписи (`text`, `line`, `polyline`, елементи з маркерами-стрілками), рамки легенд, кола-номери, прямі темні відрізки-виноски (з урахуванням `transform`, у т.ч. з `fill:#000`), малі растрові вставки й рендерить чистий PNG тієї ж пропорції — піни у відсотках лишаються чинними. Є винятки для окремих схем (`peritoneum`/`colon` — без видалення точок, `labyrinth`/`digestive` — квадрати легенди, `abdomen`/`biliary` — кольорові кола й червона мітка, `tooth` — червоні виноски, `thigh-arteries` — растри з англійськими підписами прибрано, кадр обрізано по ширині, піни перераховано в data.js).

`tools/plate_clean.py` — растрове очищення пластин Sobotta (`atlas/*.jpg`): маска кістки = закриття → заливання дірок → відкриття (тонкі лінії зникають), компоненти-«цифри» далеко від кістки відкидаються, усе поза маскою (+3 px) зафарбовується білим. Результат у `pclean/`, далі копіюється в `atlas/`. Перевірка — контактні листи «до/після» з підсвіткою видалених пікселів червоним.

Картинки кешуються браузером: після заміни файлів підняти `ATLAS_IMG_V` у `js/app.js` (додає `?v=` до `atlas/*`).

## Теорія (картки фактів)

`atlas/facts.js` — дані: `M(id, la, uk, тема, група, origo, insertio, functio, innervatio)`, `J(...)` для суглобів, `N(...)` для нервів; тема — `m1:19` (модуль:номер теми з curriculum.js). `js/facts.js` — маршрути `#/facts`, `#/facts/<тема>`, `/learn`, `/quiz`; повторення через `srsReview('fact:'+id, поле, 'q')`, тож `srsResolve` ці ключі ігнорує, а модуль сам додає блок на «Сьогодні» і бейдж. Щоб додати тип карток — новий запис у `FACTS.types` з полями `{k, uk, la}`.

## PWA і офлайн

`sw.js` — кеш `anat-vN` (піднімати N при зміні файлів оболонки); `manifest.json`; іконки в `icons/`. На «Прогрес» кнопка «Зберегти всі схеми для офлайну» шле SW список картинок (`postMessage {type:'precache'}`). Резервна копія — всі ключі `localStorage` з префіксом `anat.`.

## Заміна CC BY-SA схем на Sobotta (2026-09-05)

`tools/plate_clean2.py` — очищення нової пластини: маска рисунка (закриття → заливання → відкриття), забілювання полів, inpaint довгих прямих виносок усередині (Hough). `tools/sobotta_new_sets.py` — конвеєр для нових наборів: `BOX` — прямокутники підписів у відсотках (на білому полі — забілюються, поверх рисунка — inpaint тонких штрихів), `SETS` — id, назва, категорія та піни `(la, uk, x%, y%)`, розставлені вручну за сіткою; пише `final/<id>.jpg`, оверлеї з номерами для перевірки і `new_sets.json`, який далі вписується в `atlas/data.js` (файл, w/h, items, credit). Так замінено heart (Sobo 1906 528), kidney (1906 470), brain (1909 624), labyrinth (1911 777), biliary (1906 393), abdomen (1906 406). Пошук пластин — Commons API (`list=search`, `Sobo 1906 …`), повні файли — `Special:FilePath` з паузами (429 при паралельному завантаженні).

## М’язи (пластини Sobotta 1909, том 1)

`tools/sobotta_muscle_sets.py` — той самий конвеєр, що й для органів: `SETS[<файл>] = {id, title, cat, topics, box, items}`. Підписи тут надруковані поверх м’язів, тому `box` над рисунком стирається маскою «чорнило» (усі канали < 125; м’яз має високий R) з inpaint, а підписи на білому полі — забілюванням (режим обирається автоматично: після відкриття 9×9 у боксі не лишається темного). Виносні лінії на шкірі — окремі вузькі бокси. `tools/sobotta_muscle_install.py` вписує набори в data.js (категорія «М’язи»), додає їх у теми curriculum.js і рядки в ЛІЦЕНЗІЇ.md. Пластини 238 (глибокі м’язи спини) і 250 (глибокі м’язи живота) розмічені 2026-09-06. Стирання підписів у `erase_boxes` (tools/sobotta_new_sets.py): рамка на білому полі → забілити; поверх рисунка → маска чорнила (усі канали < 125, для чорно-білих пластин — ще blackhat) + Telea; авто-детектор майже чорних «слів» по всьому рисунку (компоненти після склеювання 3×9, прямі виносні лінії відкидаються Хафом); наприкінці — забілювання дрібних темних компонентів, оточених білим. Маска тіла пластини у plate_clean2 тримає компоненти > 1 % площі.
